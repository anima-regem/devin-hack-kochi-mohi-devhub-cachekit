# Web scaffold

Run `npm install` and `npm run dev` in this directory. `npm run build`,
`npm run typecheck`, and `npm run lint` verify the scaffold.

The initial workspace is an honest empty state, with a method and limitations
page. Analysis upload, API integration, heatmaps, fix controls, and benchmark
charts belong to later phases. Charts will add Recharts when actual result
contracts are available. This scaffold has no fabricated report or performance
data, remote font dependency, or external analytics.
